# Phase 1: write these SQL queries yourself

Use `db/schema.sql` to understand the available tables and columns. Write each
query in `exercises/phase1_answers.sql`; try it with `psql` and explain the
result before looking for help.

1. List every customer, ordered by name.
2. List products in the `Stationery` category from lowest to highest price.
3. Show each order's ID, date, quantity, and status.
4. Show each order with the customer's name.
5. Show each order with the product name and unit price.
6. Show each order's calculated line total (`quantity * unit_price`).
7. Count how many orders each customer has, including customers with no orders.
8. Calculate revenue per product using delivered orders only.
9. Find total delivered revenue by customer, highest first.
10. Find monthly delivered revenue for 2025.

Keep your answers in the order above. Do not include destructive statements.
